# Frontend Skill Pack (React / Next.js)

A comprehensive set of skills for AI agents and developers working on React and Next.js frontend projects. This repository contains guidelines and conventions for UI, State Management, API Services, Routing, Data Fetching, Forms, and Design Systems.

## Structure

This repository is organized into bilingual skill packs (English `en/` and Vietnamese `vi/`). Each folder represents a standalone skill that can be imported into [skills.sh](https://www.skills.sh).

- `01-ui-conventions`: UI Component guidelines.
- `02-store`: Global state management with Zustand.
- `03-service-and-auth`: API layers, Anti-Corruption Layer, and advanced JWT Auth token management.
- `04-router`: Next.js App Router conventions.
- `05-tanstack-query`: Data fetching and server state with TanStack Query v5.
- `06-form-validation`: Form management with React Hook Form and Zod.
- `07-design-system`: Accessibility (a11y), responsive grid, and i18n baseline.

## Usage

You can import these skills into your projects via [skills.sh](https://www.skills.sh) by pointing to this repository and selecting the specific `SKILL.md` files you need.
